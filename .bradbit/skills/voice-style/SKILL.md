# Voice and style

## Goal
Keep the prose recognizably the same book from chapter one to the end.

## Before writing
Read `bible/style.md`. If it is empty, build it with the user from
examples: POV, tense, sentence length, register, interiority, dialogue
conventions and description palette.

## Style pass
- Preserve meaning and voice; do not flatten the prose into generic
  "clean" writing.
- Cut filler, repeated gestures and explanatory dialogue.
- Check POV consistency and head-hopping.
- Vary rhythm; read paragraphs aloud mentally.
- Keep the book's lexicon and avoid anachronisms.

## Example (Spanish)
> **Antes:** "Ella se sintió muy triste y no sabía qué hacer."
> **Después:** "Guardó la carta en el cajón y se quedó mirando la llave,
> como si todavía pudiera decidir no abrir nada."

## Do not
- Do not impose a different style because it is fashionable.
- Do not rewrite a whole chapter in a style pass without approval.
